## Hook
* Start with a rhetorical question about AP calculus: "Did you know that either AP calculus exams can save you at least one full semester of calculus in college?"
  * Reasoning/purpose: "This is why I made a project designed to help students memorize key concepts on the AP calculus exam."

## Process
* How I utilized reactive arrays (then objects) to hold the question information
  * How I pulled information from the deck object and specific subject arrays.
* How I used Vue.js (JS framework) to allow my website to be a single page application
  * No redirections to other HTML pages, with simple Vue conditionals HTML can then be toggled.
  * Very useful, as all I needed to do was set conditions for certain HTML to be seen at different times.
    * Ex. If the user wanted to play the unitCircle deck, it would toggle the "play" screen and use the unitCircle deck's questions. 
* Using short code snippets and short gifs specifically for each function I discuss(?)

## Conclusion
* Takeaways
  * Don't be hesitant to learn uncovered concepts you think would benefit you. 
    * Ex. Involvement with CSS transitions (wasn't my targeted topic in SEP10), setTimeout (JS), .sort with arrays (JS)
      * For the right/wrong answer animation, and reorganizing the answer choices
  * Working on time management if you're ambitious is important.
    * I wanted to add many more decks and more features (like feedback even though this is for memorization mostly), and I especially like the beyond MVP ideas my peers gave me. However, I wasn't able to get to them besides adding more decks (obviously needed for more variety).
